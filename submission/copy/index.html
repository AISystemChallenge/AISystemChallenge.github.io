원클릭 복사

대회 등록 화면(GitHub 저장소 연결)의 값을 버튼 한 번으로 복사합니다. 등록 화면의 「원클릭 복사 화면 열기」로 이 화면을 열면 값이 채워집니다.

표시할 값이 없습니다. 대회 등록 화면의 「원클릭 복사 화면 열기」로 이 화면을 여세요. 주소만 직접 열면 값이 비어 있습니다.

이 링크의 값이 대회 공식 형식과 다릅니다. 등록 화면의 '원클릭 복사 화면 열기'로 다시 여세요. 이 값을 GitHub에 입력하지 마세요.

링크에 일부 값이 없습니다. 등록 화면의 '원클릭 복사 화면 열기'로 다시 여세요.

GitHub 설정 체크리스트

  1. 저장소 Settings → Collaborators → Add people에서 위 Collaborator 사용자명을 Write 이상 권한으로 초대합니다. 조직 저장소는 Collaborators and teams에서 초대합니다.
  2. Settings → Webhooks → Add webhook을 선택합니다. 이미 대회 webhook을 만들어 두었다면 그대로 두고 새로 만들지 않아도 됩니다.
  3. Payload URL과 Secret에 위 값을 붙여넣습니다. 값은 바꾸지 않습니다.
  4. Content type은 application/json, SSL verification은 Enable SSL verification(활성)으로 둡니다.
  5. Which events would you like to trigger this webhook?에서 Let me select individual events를 선택하고 Releases만 체크합니다. 기본으로 체크되어 있는 Pushes는 체크를 해제합니다. Active는 체크한 채로 둡니다.
  6. Add webhook으로 저장한 뒤 등록 화면으로 돌아가 「설정 완료 · 자동 연결 테스트 시작」을 누릅니다.
